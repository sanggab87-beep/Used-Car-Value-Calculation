# 캐릭터 이미지 넣는 법 (실제 티니핑 그림 쓰기)

이 폴더에 아래 **파일 이름 그대로** 이미지를 넣으면, 게임이 자동으로 그 그림을 씁니다.
파일이 없으면 코드로 그린 임시 그림이 대신 나옵니다.

| 파일 이름 | 캐릭터 | 쓰이는 곳 |
|---|---|---|
| `romi.png` | 로미 (주인공) | 전투 화면 |
| `hachuping.png` | 하츄핑 | 전투 화면 |
| `diana.png` | 다이아나핑 | 스토리·전투 |
| `eclipse.png` | 이클립스핑 | 보스 전투 |
| `royal.png` | 로열 티니핑 | 마을 NPC |
| `darkbit.png` | 어둠 조각 | 잡몹 전투 |

## 팁
- **정사각형(예: 256×256) PNG**가 가장 잘 맞아요. 배경은 투명(투명 PNG)이면 제일 예쁩니다.
- 그림은 딸이 좋아하는 걸로 자유롭게 넣으세요. 이름만 위 표와 같으면 됩니다.
- 이미지를 넣은 뒤 게임 페이지를 새로고침하면 바로 반영됩니다.
