# 캐릭터 이미지 넣는 법 (실제 티니핑 그림 쓰기)

이 폴더(`game/assets/`)에 아래 **파일 이름 그대로** 이미지를 넣으면, 게임이 자동으로 그 그림을 씁니다.
파일이 없으면 코드로 그린 임시 그림이 대신 나옵니다.

> 파일 이름은 반드시 아래와 똑같아야 해요 (게임이 이 이름으로 그림을 찾습니다).

## 팁
- **정사각형(예: 256×256) PNG**가 가장 잘 맞아요. 배경은 투명(투명 PNG)이면 제일 예쁩니다.
- 넣고 싶은 것만 넣어도 돼요. 없는 건 자동으로 임시 그림이 나옵니다.
- 이미지를 넣은(커밋한) 뒤 게임 페이지를 새로고침하면 반영됩니다.
