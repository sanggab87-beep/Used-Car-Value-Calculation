## 로미 걷기 스프라이트 (선택 · 발걸음 애니메이션)
방향별로 걷는 프레임 2장씩 넣으면 발을 번갈아 딛는 애니메이션이 돼요.
파일이 없으면 코드 걷기 연출(통통/살랑)로 자동 폴백합니다.

| 파일 이름 | 방향 | 프레임 |
|---|---|---|
| `romi_down_1.png`, `romi_down_2.png` | 남(아래로 걷기) | 1·2 |
| `romi_up_1.png`, `romi_up_2.png` | 북(위로 걷기) | 1·2 |
| `romi_left_1.png`, `romi_left_2.png` | 서(왼쪽) | 1·2 |
| `romi_right_1.png`, `romi_right_2.png` | 동(오른쪽) | 1·2 |

- 프레임은 최대 3장까지(`_1`,`_2`,`_3`) 인식해요.
- **서/동 중 한쪽만** 만들어도 됩니다 — 없는 쪽은 좌우반전으로 자동 생성.
- 한 방향이라도 비면 그 방향은 코드 연출로 폴백해요.

## 팁
- **정사각형(예: 256×256) 투명 PNG**가 가장 잘 맞아요.
- 걷기 프레임은 **몸 위치·크기 고정, 다리(발)만 바뀌게** 만들면 번갈아 볼 때 안 튀어요. 발은 그림 아래쪽 중앙에 오게.
- 넣고 싶은 것만 넣어도 됩니다. 없는 건 자동으로 임시 그림/연출이 나와요.
- 이미지를 넣은(커밋한) 뒤 게임 페이지를 새로고침하면 반영됩니다.
